Transmon Pocket Charge Line
===========================

Create a standard pocket transmon qubit for a ground plane,

.. image:: ../images/qlibrary/TransmonPocketCL.png
   :alt: Transmon Pocket Charge Line
   :width: 220px

**Class** ``TransmonPocketCL`` · **Module** ``qiskit_metal.qlibrary.qubits.transmon_pocket_cl`` · **Category** qubits

**Inherits** ``TransmonPocket`` → ``BaseQubit`` → ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.qubits.transmon_pocket_cl import TransmonPocketCL

   design = designs.DesignPlanar()
   comp = TransmonPocketCL(design, "transmonPocketCL1", options=dict())
