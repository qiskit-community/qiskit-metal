Star Qubit
==========

A single configurable circle with multiple pads.

.. image:: ../images/qlibrary/StarQubit.png
   :alt: Star Qubit
   :width: 220px

**Class** ``StarQubit`` · **Module** ``qiskit_metal.qlibrary.qubits.star_qubit`` · **Category** qubits

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.qubits.star_qubit import StarQubit

   design = designs.DesignPlanar()
   comp = StarQubit(design, "starQubit1", options=dict())

Pins
----

``pin_cpl1``, ``pin_cpl2``, ``pin_cpl3``, ``pin_cpl4``, ``pin_rdout``

Pin names of the instance built for this page; some components add or rename pins from their options.
