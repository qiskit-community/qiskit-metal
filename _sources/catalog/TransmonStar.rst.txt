Transmon Star
=============

A transmon island with ``num_points`` radial arms evenly spaced around

.. image:: ../images/qlibrary/TransmonStar.png
   :alt: Transmon Star
   :width: 220px

**Class** ``TransmonStar`` · **Module** ``qiskit_metal.qlibrary.qubits.transmon_star`` · **Category** qubits

**Inherits** ``BaseQubit`` → ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.qubits.transmon_star import TransmonStar

   design = designs.DesignPlanar()
   comp = TransmonStar(design, "transmonStar1", options=dict())

Pins
----

None with the default options. Pins appear when the options define connection pads, ports, or flux lines.
