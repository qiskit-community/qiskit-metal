Transmon Pocket
===============

Create a standard pocket transmon qubit for a ground plane,

.. image:: ../images/qlibrary/TransmonPocket.png
   :alt: Transmon Pocket
   :width: 220px

**Class** ``TransmonPocket`` · **Module** ``qiskit_metal.qlibrary.qubits.transmon_pocket`` · **Category** qubits

**Inherits** ``BaseQubit`` → ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.qubits.transmon_pocket import TransmonPocket

   design = designs.DesignPlanar()
   comp = TransmonPocket(design, "transmonPocket1", options=dict())

Pins
----

None with the default options. Pins appear when the options define connection pads, ports, or flux lines.
