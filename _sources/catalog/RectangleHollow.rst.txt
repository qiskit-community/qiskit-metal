Rectangle Hollow
================

A single configurable square.

.. image:: ../images/qlibrary/RectangleHollow.png
   :alt: Rectangle Hollow
   :width: 220px

**Class** ``RectangleHollow`` · **Module** ``qiskit_metal.qlibrary.sample_shapes.rectangle_hollow`` · **Category** sample shapes

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.sample_shapes.rectangle_hollow import RectangleHollow

   design = designs.DesignPlanar()
   comp = RectangleHollow(design, "rectangleHollow1", options=dict())

Pins
----

None with the default options. Pins appear when the options define connection pads, ports, or flux lines.
