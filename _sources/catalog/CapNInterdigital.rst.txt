Cap N Interdigital
==================

Generates a two pin (+) structure comprised of a north CPW transmission

.. image:: ../images/qlibrary/CapNInterdigital.png
   :alt: Cap N Interdigital
   :width: 220px

**Class** ``CapNInterdigital`` · **Module** ``qiskit_metal.qlibrary.lumped.cap_n_interdigital`` · **Category** lumped

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.lumped.cap_n_interdigital import CapNInterdigital

   design = designs.DesignPlanar()
   comp = CapNInterdigital(design, "capNInterdigital1", options=dict())

Pins

Pin names of the instance built for this page; some components add or rename pins from their options.
