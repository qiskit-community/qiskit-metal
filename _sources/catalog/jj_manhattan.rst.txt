Josephson Junction Manhattan
============================

Manhattan-style Josephson junction.

.. image:: ../images/qlibrary/jj_manhattan.png
   :alt: Josephson Junction Manhattan
   :width: 220px

**Class** ``jj_manhattan`` · **Module** ``qiskit_metal.qlibrary.qubits.JJ_Manhattan`` · **Category** qubits

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.qubits.JJ_Manhattan import jj_manhattan

   design = designs.DesignPlanar()
   comp = jj_manhattan(design, "jj_manhattan1", options=dict())

Pins
----

None with the default options. Pins appear when the options define connection pads, ports, or flux lines.
