Line Tee
========

Generates a three pin (+) structure comprised of a primary two pin CPW

.. image:: ../images/qlibrary/LineTee.png
   :alt: Line Tee
   :width: 220px

**Class** ``LineTee`` · **Module** ``qiskit_metal.qlibrary.couplers.line_tee`` · **Category** couplers

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.couplers.line_tee import LineTee

   design = designs.DesignPlanar()
   comp = LineTee(design, "lineTee1", options=dict())

Pins
----

``prime_end``, ``prime_start``, ``second_end``

Pin names of the instance built for this page; some components add or rename pins from their options.
