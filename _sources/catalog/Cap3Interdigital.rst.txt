Cap 3 Interdigital
==================

Create a three finger planar capacitor with a ground pocket cuttout.

.. image:: ../images/qlibrary/Cap3Interdigital.png
   :alt: Cap 3 Interdigital
   :width: 220px

**Class** ``Cap3Interdigital`` · **Module** ``qiskit_metal.qlibrary.lumped.cap_3_interdigital`` · **Category** lumped

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.lumped.cap_3_interdigital import Cap3Interdigital

   design = designs.DesignPlanar()
   comp = Cap3Interdigital(design, "cap3Interdigital1", options=dict())
