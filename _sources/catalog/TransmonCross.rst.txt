Transmon Cross
==============

Simple Metal Transmon Cross object. Creates the X cross-shaped island,

.. image:: ../images/qlibrary/TransmonCross.png
   :alt: Transmon Cross
   :width: 220px

**Class** ``TransmonCross`` · **Module** ``qiskit_metal.qlibrary.qubits.transmon_cross`` · **Category** qubits

**Inherits** ``BaseQubit`` → ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.qubits.transmon_cross import TransmonCross

   design = designs.DesignPlanar()
   comp = TransmonCross(design, "transmonCross1", options=dict())

Pins
----

None with the default options. Pins appear when the options define connection pads, ports, or flux lines.
