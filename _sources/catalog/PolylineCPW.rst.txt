CPW along an explicit list of points
====================================

A coplanar waveguide drawn along an explicit polyline.

.. image:: ../images/qlibrary/PolylineCPW.png
   :alt: CPW along an explicit list of points
   :width: 220px

**Class** ``PolylineCPW`` · **Module** ``qiskit_metal.qlibrary.tlines.polyline_cpw`` · **Category** tlines

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.tlines.polyline_cpw import PolylineCPW

   design = designs.DesignPlanar()
   comp = PolylineCPW(design, "polylineCPW1", options=dict())
