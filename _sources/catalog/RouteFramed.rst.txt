Routed Frame
============

A non-meandered sample_shapes CPW that is auto-generated between 2 components.

.. image:: ../images/qlibrary/RouteFramed.png
   :alt: Routed Frame
   :width: 220px

**Class** ``RouteFramed`` · **Module** ``qiskit_metal.qlibrary.tlines.framed_path`` · **Category** tlines

**Inherits** ``QRoute`` → ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.tlines.framed_path import RouteFramed

   design = designs.DesignPlanar()
   comp = RouteFramed(design, "routeFramed1", options=dict())

Pins
----

``end``, ``start``

Pin names of the instance built for this page; some components add or rename pins from their options.
