Rectangle
=========

A single configurable square.

.. image:: ../images/qlibrary/Rectangle.png
   :alt: Rectangle
   :width: 220px

**Class** ``Rectangle`` · **Module** ``qiskit_metal.qlibrary.sample_shapes.rectangle`` · **Category** sample shapes

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.sample_shapes.rectangle import Rectangle

   design = designs.DesignPlanar()
   comp = Rectangle(design, "rectangle1", options=dict())

Pins
----

None with the default options. Pins appear when the options define connection pads, ports, or flux lines.

---------------

   "``width``", "``'500um'``"
