Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.tlines.airbridge import Airbridge

   design = designs.DesignPlanar()
   comp = Airbridge(design, "airbridge1", options=dict())
