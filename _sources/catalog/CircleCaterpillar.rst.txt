Circle Caterpillar
==================

A single configurable circle.

.. image:: ../images/qlibrary/CircleCaterpillar.png
   :alt: Circle Caterpillar
   :width: 220px

**Class** ``CircleCaterpillar`` · **Module** ``qiskit_metal.qlibrary.sample_shapes.circle_caterpillar`` · **Category** sample shapes

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.sample_shapes.circle_caterpillar import CircleCaterpillar

   design = designs.DesignPlanar()
   comp = CircleCaterpillar(design, "circleCaterpillar1", options=dict())

Pins
----

None with the default options. Pins appear when the options define connection pads, ports, or flux lines.
