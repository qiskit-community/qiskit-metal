Route Meander
=============

Implements a simple CPW, with a single meander.  The base

**Class** ``RouteMeander`` · **Module** ``qiskit_metal.qlibrary.tlines.meandered`` · **Category** tlines

**Inherits** ``QRoute`` → ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.tlines.meandered import RouteMeander

   design = designs.DesignPlanar()
   comp = RouteMeander(design, "routeMeander1", options=dict())
