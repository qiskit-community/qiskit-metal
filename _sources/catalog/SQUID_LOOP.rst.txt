Squid Loop
==========

This creates a simple SQUID loop consisting of two Josephson

.. image:: ../images/qlibrary/SQUID_LOOP.png
   :alt: Squid Loop
   :width: 220px

**Class** ``SQUID_LOOP`` · **Module** ``qiskit_metal.qlibrary.qubits.SQUID_loop`` · **Category** qubits

**Inherits** ``QComponent``

Usage
-----

.. code-block:: python

   from qiskit_metal import designs
   from qiskit_metal.qlibrary.qubits.SQUID_loop import SQUID_LOOP

   design = designs.DesignPlanar()
   comp = SQUID_LOOP(design, "sQUID_LOOP1", options=dict())

Pins
----

None with the default options. Pins appear when the options define connection pads, ports, or flux lines.
