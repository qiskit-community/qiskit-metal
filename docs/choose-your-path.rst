##################
Choose your path
##################

Each path is an ordered list of notebooks from different parts of the site.
Every notebook in a path shows a box with its position, the previous and the
next step. Start with the :doc:`quickstart` page, then pick the path closest to
your goal. The full course is under :doc:`tut/index`.
